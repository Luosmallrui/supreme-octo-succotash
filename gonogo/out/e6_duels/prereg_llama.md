# 预注册：在第二个模型家族上确认选择规则（Llama-3.1-8B，2026-11-28）

## 为什么要确认

论文第 8 节的选择规则有三个成分是在看过 Qwen3 数据之后才加的：
- 答案层面随机效应 τ²（Eq. 2 的一般权重）；
- 不用标签的 EM；
- 不按答案分组的候选级对决。

另外，第 7 节"校准失效、循环移位投票崩溃"的诊断目前只在 Qwen3 上有自然集结果。本计划在没有参与任何规则设计的评审 Llama-3.1-8B-Instruct 上做一次确认。

**规则、实现、折、种子、阈值和多重比较校正在看到 Llama 数据之前全部固定。**

## 数据（尚未分析）

- **队列 18**（`run_queue18.sh`）：Llama-3.1-8B 评 Qwen3-8B 的自然集。
  - 答案对决：每个不同答案取一个代表，所有有序对，共 3,962 次；
  - N = 8 的 130 个集合上全部候选的有序对，共 7,280 次。
- **队列 19**（`run_queue19.sh`）：同一评审的列表式调用（E1 设计，direct）。每个集合 3 个随机顺序和多数答案在前的顺序，每个问题一个集合的全部循环移位，共 6,224 次。
- **读出**：本地权重、vLLM（bf16）、Llama-3.1 的参考 chat template（含默认 system 轮）。预填 "The best solution is Solution "，读编号的下一 token 分布。Llama 3 把 1–32 都编成单个 token，所以 `e1_run.py` 用一次读出，对决只有编号 1、2。
- **数据未看声明**：本文件和下列代码提交之前，分析者没有看过任何 Llama 自然集或对决数据。队列 18 可能已在服务器上开始，但其输出没有被读取或推送。

## 固定的实现

即本文件所在提交中的版本：
- `confirm_rules.py`：8 项检验与报告；
- `bayes_select.py`：`listwise_per_set` 的列表方法 raw1、pride1、vote3、cycsum、ours-cyc、ours3；
- `e6_em.py`：`evaluate` 的 list_ours3、duel_re 和 em_shared，以及作为参照的 duel_prereg、em_group；
- `e6_allcand.py`：`evaluate` 的 budget 和 vote3c；
- `e6_checks.fit_duel`。

各规则的定义：
- **duel_re**：Eq. 2，权重 δ/(σ²ε + Kτ²)，有标签、5 折交叉拟合（按原题分折，折与 E1 相同）。
- **em_shared**：不用标签的 EM，δ、τ²、σ²ε 跨组共享，γ 按组（来源 × N）。实现与 `report_e6_em.md` 完全相同，含 γ 的上界 12；γ 的修补不在本次确认之内。
- **budget**：在 3 顺序投票的 token 预算内能做的随机双序对数，用最小二乘打分，每个集合 200 次抽样取平均（种子固定）。
- **vote3c**：3 个随机顺序按候选计票，不用答案。

命令：

```bash
python confirm_rules.py --judge llama-3.1-8b --model qwen3-8b --data results \
    --calls out/e1_direct_llama-3.1-8b_on_qwen3-8b.jsonl --duels out/e6_duels/e6_llama-3.1-8b_on_qwen3-8b.jsonl \
    --allcand out/e6_duels/e6_allcand_N8_llama-3.1-8b_on_qwen3-8b.jsonl --output out/e6_duels/confirm_llama-3.1-8b.md
```

## 登记的检验

差值为准确率之差，单位 pp。区间按原题整群重采样 20,000 次，对 8 项检验做 Bonferroni 校正（99.375% 区间）。校正区间落在阈值的预测一侧，该项即为确认；否则为未确认。

| 编号 | 主张 | 比较 | 集合 | 预测 |
|---|---|---|---|---|
| L1 | 按槽位先验校准会降低准确率 | pride1 − raw1 | N ≥ 8 | < 0 |
| L2 | 对全部循环移位投票会崩溃 | cycsum − vote3 | N ≥ 16，有循环移位 | < 0 |
| L3 | 列表后验能救回循环移位 | ours-cyc − cycsum | 有循环移位的全部集合 | > 0 |
| D1 | 对决后验胜过列表后验 | duel_re − list_ours3 | 全部 | > 0 |
| D2 | 对决后验胜过多数投票 | duel_re − majority | 全部 | > 0 |
| D3 | 不用标签的 EM 胜过多数投票 | em_shared − majority | 全部 | > 0 |
| D4 | EM 比有监督差不超过 3 pp | em_shared − duel_re | 全部 | > −3 |
| C1 | 不分组的对决胜过按候选计票的 3 顺序投票 | budget − vote3c | N = 8 | > 0 |

**预测依据**：
- **D1 体现论文的"位置束缚程度"假说**：列表选择越受位置束缚，对决越有用。Llama 在 E2 上的首位效应为 +43 / +52（托管）和 +51.5 / +67.9（本地），属于强位置束缚。所以预测 D1 成立；这与 DeepSeek（首位效应 +21.5，对决只追平列表后验）形成对照。
- **L1–L3** 预测第 7 节的诊断在另一个家族上复现。
- **C1** 预测第 8 节不用答案键的结果在另一个家族上复现。

## 在开发数据上的试运行

为确认代码能端到端运行，`confirm_rules.py` 在 Qwen3-8B 自评的数据上跑过一次，结果见 `confirm_dryrun_qwen3-8b.md`。这些数据参与了规则设计，所以不算确认。

- 试运行复现了论文中的数字：+6.1、+5.6、+4.3、−1.8、+12.7、+14.9。
- 8 项中 7 项满足判定标准，**D4 不满足**：差值 −1.8，但 Bonferroni 区间下限 −5.0，低于 −3。

D4 的 3 pp 界限按实质意义设定，看到试运行结果后不改。这说明在这个样本量下 D4 的检验力有限，所以 Llama 上 D4 未确认时，不能单独解读为 EM 明显不如有监督。

## 数据质量门槛（在看任何准确率之前检查）

- 列表调用的编号概率质量均值 ≥ 0.9；
- 列表调用至少完成计划的 95%，且 ≥ 98% 的集合有全部 3 个随机顺序；
- 对决文件通过队列脚本的完整性检查。

不满足时，只修读出或补跑缺失调用，不看准确率，并在报告中写明。
